# Code of Conduct

## Our Pledge

`mini-criu` is an educational systems project. The goal is to make low-level
Linux checkpoint/restore mechanics easier to study, discuss, and improve.

Everyone participating in this project is expected to keep discussions
respectful, technical, and welcoming.

## Expected Behavior

- Be respectful when reviewing code, diagnostics, and ideas.
- Assume good intent, especially when someone is learning systems concepts.
- Keep feedback specific and actionable.
- Respect the project's narrow scope and documented limitations.
- Avoid sharing private checkpoint artifacts, memory dumps, credentials, or
  sensitive machine details.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publicly posting exploit details or sensitive checkpoint data.
- Repeatedly pushing unsupported production or offensive-security use cases.
- Disruptive behavior that prevents maintainers or contributors from working.

take other reasonable action to keep the project safe and focused.
